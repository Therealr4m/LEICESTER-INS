# Branding files

Colours: navy #203f61, dark text #182d42, amber #edb34e.

`branding-assets/logo.svg` and `mark.svg` are editable vectors. Root PNG and ICO files provide browser and Apple icons. The header uses the same house symbol as inline SVG.

After replacing icons, keep filenames or update every HTML head. Browser favicon caches may require a hard refresh.
